skeleton · clone de layout

Copiamos o layout. Não o conteúdo.

O skeleton abre uma página no Chromium, preserva o DOM e o CSS renderizados e troca todo o texto por lorem ipsum e as imagens por placeholders. A estrutura continua igual; a informação, não.
